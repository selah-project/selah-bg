## The Hebrew text

The underlying Hebrew source (OSHB / WLC 4.20) is in the public
domain. This license applies **only** to the rendering, the glosses,
the marks and the revision history — those are original to the Selah
project.

## The script

Bulgarian Cyrillic is the script Bulgarians read, and it is the only
script this rendering is published in. A Latin transliteration, if one
is ever made, would be a sibling rendering — never a substitute for
this one.
